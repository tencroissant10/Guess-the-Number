# ナンバーコール

通話しながら 2〜8 人で遊ぶ数字あてゲームです。
参加した順に輪になり、ひとりが「次の人が当てる数字」を決めます。自分のターンに通話で質問し、
わかったら数字を入力します。当たれば勝ち、はずれたら次の人のターンです。

選べる数字は 0〜9000兆 です。

| 範囲 | 選べる数字 |
| --- | --- |
| 0〜100 | すべて |
| 100〜1000 | 頭2桁（110, 530 …） |
| 1000〜1万 | 頭1桁（1000, 2000 … 9000） |
| 万・億・兆 | 上と同じ決まりに単位がつく（530万, 3000億, 9000兆 …） |

ロビーで範囲を決めると、数字を選ぶ欄にはその範囲の数字と単位しか出ません。

### ヒント

3回答えるごとにヒントを1回使えます（パスは数えません）。自分のターンに使え、使ってもターンは続きます。

- **一番近い回答を見る** — 今まで自分が答えた数字の中で、正解に一番近いものがわかります。
- **以上？未満？を聞く** — 数字をひとつ選ぶと、正解がその数字「以上」か「未満」かがわかります。

ヒントの結果は回答の記録に残り、全員に見えます。

## ファイル

- `server.js` — ゲームのサーバー（Node.js だけで動きます。追加のパッケージは不要です）
- `public/index.html` — ゲームの画面
- `number-call.html` — 以前の claude.ai 版（このサーバーでは使いません）

## 自分のパソコンで動かす

Node.js 18 以上が必要です。

```bash
node server.js
```

ブラウザで http://localhost:3000 を開きます。ポートを変えたいときは、環境変数 `PORT` を設定します（PowerShell の例: `$env:PORT=8080; node server.js`）。

同じ Wi-Fi の人なら、`http://<このパソコンのIPアドレス>:3000` で参加できます（Windows のファイアウォールで許可が必要な場合があります）。

## 離れた人と遊ぶ（インターネットに公開する）

通話相手が別の場所にいる場合は、サーバーをインターネットから見えるようにします。

- **一時的に公開する**: パソコンで `node server.js` を動かしたまま、Cloudflare Tunnel や ngrok などのトンネルサービスで `localhost:3000` を公開し、出てきた URL を相手に送ります。
- **常に置いておく**: Render・Railway・Fly.io などの Node.js が動くホスティングにこのフォルダをそのまま置き、起動コマンドを `npm start` にします。ポートはサービスが渡す `PORT` を自動で使います。

## しくみと注意点

- ルームの情報はサーバーのメモリにだけあります。サーバーを再起動するとルームは消えます。誰も接続していないルームは 6 時間で自動的に消えます。
- 数字の判定はサーバーで行い、見てはいけない数字はその人のブラウザに送りません（開発者ツールを使っても見えません）。
- 画面の更新には Server-Sent Events を使っています。リバースプロキシの後ろに置く場合は、レスポンスのバッファリングを切ってください。
- 同じブラウザの複数タブは同じ人として扱われます。ひとりで動作を試すときは、別のブラウザやシークレットウィンドウを使ってください。
